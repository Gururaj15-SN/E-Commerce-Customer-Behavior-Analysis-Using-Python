# E-Commerce Customer Behavior Analysis Using Python

## Project Overview
This project analyzes e-commerce transactions to identify sales trends, product performance, customer spending patterns, and purchasing behavior using Python and data visualization.

## Objectives
- Analyze monthly sales trends.
- Identify high-revenue product categories.
- Examine customer spending and purchase recency.
- Segment customers using recency and monetary value.
- Study correlations between customer behavior and transaction variables.
- Evaluate revenue concentration using Pareto analysis.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Google Colab
- Jupyter Notebook

## Key Findings
- Total revenue: 4,915,544.57
- Highest sales month: January 2024
- Lowest sales month: April 2023
- Leading product category: Electronics
- Most-used payment method: Credit Card
- Revenue from the top 20% of customers: 72.04%

## Visualizations
- Age and transaction amount distributions
- Monthly sales trend
- Customer segment comparison
- Customer behavior correlation heatmap
- Pareto revenue analysis

## Methodology
1. Load and inspect transaction data.
2. Check missing values, duplicates, and data types.
3. Perform exploratory data analysis.
4. Analyze monthly sales and category performance.
5. Calculate customer-level recency and monetary value.
6. Create provisional customer segments.
7. Visualize correlations and revenue concentration.

## Limitation
The dataset contains one recorded transaction per customer. Therefore, frequency-based loyalty analysis and independently verified churn prediction were not possible. Customer segments are based on recency and monetary value.

## Conclusion
The analysis highlights revenue concentration, strong-performing product categories, and monthly sales patterns. These insights demonstrate how Python-based analytics can support business reporting and customer strategy decisions.
